# موقع دَعمة للحلول الرقمية

**Vite + React 19 + TypeScript + Tailwind v4** — عربي بالكامل (RTL)، تصميم إديتوريالي فاتح.

```bash
npm run dev     # http://localhost:4100
npm run build
```

## البنية

| المسار | الوصف |
|---|---|
| `src/content/site.ts` | **كل النصوص والأسعار** — عدّل من هنا فقط |
| `src/styles/globals.css` | نظام التصميم: الألوان، مقاييس الطباعة، الحركة |
| `src/styles/fonts.css` | Tajawal مستضاف محليًا (مولّد آليًا، 7 أوزان) |
| `src/components/primitives.tsx` | Btn · TextLink · Index · Reveal · Lines · HandArrow · ScrollProgress |
| `public/fonts/` · `public/assets/` | الخطوط · اللوجو وصور الأعمال |
| `BRAND-BRIEF.md` | تحليل الملف التعريفي الكامل |

## الهوية

```
الأحمر  #e40000      الأبيض  #ffffff      الأسود  #000000
```

محايدات مشتقّة للأسطح: `--color-shell #f6f4f2` · `--color-shell-2 #eceae6` · `--color-ink #0d0c0c`

**مقاييس الطباعة** — التباين بين الوزن 200 والوزن 800 هو ما يصنع الإحساس الإديتوريالي:

| الصنف | الاستخدام |
|---|---|
| `.display` | عنوان الهيرو — وزن 800، تباعد سطور 0.99 |
| `.h2` | عناوين الأقسام — clamp حتى 3rem |
| `.lede` | جملة المانيفستو — **وزن 200**، ضخمة وخفيفة |
| `.body` | نص الجسم — تباعد سطور 1.95 |
| `.idx` | رقم فهرس القسم في الهامش |

## قواعد لازم تتحافظ عليها

**١. الحركة لا تُخفي المحتوى أبدًا.** المحتوى ظاهر افتراضيًا. الحركات مفعّلة فقط عبر
`.anim-ready` التي تُضاف على `<html>` من `main.tsx` **قبل أول رسم** — وفقط إذا كانت
الصفحة مرئية والمستخدم لا يفضّل تقليل الحركة. السبب: أي حركة تبدأ من `opacity:0`
تترك المحتوى مخفيًا للأبد لو لم تُشغَّل (تبويب مخفي، محرّك بلا تركيب إطارات).
`Reveal` كذلك يُظهر المحتوى فورًا لو `IntersectionObserver` غير مدعوم.

**٢. `overflow-x: clip` على `html` و`body` — وليس `hidden`.** مع `hidden` يصبح
العنصر حاوية تمرير فينزاح أصل الرسم في RTL وتظهر الصفحة فارغة على الموبايل.
وأي عنصر زخرفي كبير لازم يكون **مقيّدًا بالعرض** لا بالارتفاع.

**٣. التوسيط في RTL:** استخدم `inset-x-0 mx-auto w-fit` لا `start-1/2 -translate-x-1/2`.

**٤. الخطوط مستضافة محليًا** — البناء لا يعتمد على شبكة. لتحديثها أعد توليد
`src/styles/fonts.css` مع ملفات `public/fonts/`.
